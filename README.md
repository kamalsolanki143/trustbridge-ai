# 🚀 TrustBridge AI

> **AI-Powered Explainable Credit Readiness Platform for MSMEs**

TrustBridge AI is an intelligent underwriting platform that helps financial institutions evaluate MSME loan applications using Explainable AI and consent-based financial intelligence.

---

## 🌟 Problem Statement

Traditional MSME loan underwriting is:

- Slow
- Manual
- Non-transparent
- Dependent on limited credit history

As a result, many deserving MSMEs struggle to access credit.

---

# 💡 Our Solution

TrustBridge AI generates an AI-powered Trust Score using multiple verified financial data sources including:

- GST
- Account Aggregator
- UPI Transactions
- Invoice Data
- Business Profile

The platform provides:

- Explainable Trust Score
- Credit Readiness Assessment
- AI Risk Analysis
- Personalized Improvement Suggestions
- Transparent Lending Decisions

# ⚙️ Local Setup

```bash
git clone https://github.com/kamalsolanki143/trustbridge-ai.git

cd trustbridge-ai

cd backend

python -m venv .venv

pip install -r requirements.txt

python -m uvicorn app.main:app --reload
```

Frontend

```bash
cd frontend

npm install

npm run dev
```
